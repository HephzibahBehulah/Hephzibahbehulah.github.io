# HB Intelligence Portfolio

A browser-first technical learning platform by Hephzibah Behulah.

## Platform architecture

- Home — intelligence portfolio and primary workspace
- Intelligence — Intelligence Tree, Resource Matrix, Knowledge Library and Ebook Vault
- Security — Recon Hub and Pentest Lab
- Tools — Toolbench, Mega Tools and Engineering Library
- Work — Projects and engineering-focused work
- Identity — About
- Contact — professional communication channels

## Legacy URL policy

The former portfolio.html and resources.html routes are retained as lightweight redirects so older bookmarks and indexed links do not become dead ends.

about.html, contact.html and pentest.html remain dedicated pages and now follow the same information architecture and visual language as the main platform.

## Safety boundary

The Pentest Lab is designed for authorised learning. Browser functionality is limited to safe demonstrations. Intrusive testing belongs in an explicitly authorised local laboratory.

## Engineering Library

The Engineering Library contains original browser calculators and a live link to the external CalcEngineer directory. External material remains attributed to its source rather than copied into this repository.
