# Cyber OS data expansion

This directory is the expansion boundary for large, source-backed catalogs.

Recommended collections:

- networking
- ports
- protocols
- windows-commands
- powershell
- linux-commands
- shortcuts
- power-tricks
- detection-patterns
- tools
- frameworks
- osint-sources
- threat-actors
- security-teams
- formulas
- glossary
- scenarios
- quizzes

Every record should follow content-schema.json. Large datasets should be generated from authoritative source material and reviewed before publication.

Do not create filler records merely to reach a requested number. A count is meaningful only when the underlying records are real, distinct and useful.
