# Generated Cyber OS catalogs

These files are generated by source synchronization jobs. They are not hand-filled to satisfy numeric targets.

Sources wired into the scale pipeline:
- IANA service-name and port registry
- MITRE ATT&CK Enterprise STIX data
- Microsoft Windows Server command documentation
- Microsoft PowerShell documentation
- Linux man-pages
- RFC Editor index

Generated records retain source, source URL and verification metadata. If a source cannot be fetched or validated, the synchronization job fails rather than fabricating records.
