INSTALLATION POLICY & SAFETY

Cyber-OS is a reference and learning interface. It does not run commands on your computer or remotely install tools.

  • Prefer official releases, distribution repositories and signed packages.
  • Inspect scripts before executing them; avoid piping remote scripts directly to a shell.
  • Use least privilege; do not add sudo unless the documented task requires it.
  • Use private, isolated virtual machines or intentionally vulnerable labs for active tests.
  • Keep API keys, passwords, private keys and captured traffic out of public logs.

The third-party “bug bounty toolkit” script is not a default installer recommendation. If you choose to inspect it, download for review first: curl -fsSLo /tmp/bug-bounty-toolkit-install.sh https://raw.githubusercontent.com/shayanrsh/bug-bounty-toolkit-install-script/main/install.sh, then read it with less /tmp/bug-bounty-toolkit-install.sh. Do not execute it until you have audited its contents, dependencies and permissions.
