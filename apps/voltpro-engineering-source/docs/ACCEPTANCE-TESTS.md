# VoltPRo Acceptance Tests

## Beginner
Build source → switch → lamp → source in under two minutes. Run the circuit and see current/power.

## Professional electrical
Load the motor-starter exercise and verify the expected topology includes a three-phase source, protective device, contactor, motor and PE.

## Embedded
Load the Arduino challenge, map a GPIO to a virtual LED, execute a Blink-compatible program through the future MCU runtime adapter, and observe the virtual output plus serial monitor.

## Engineering integrity
- No result may be presented as a real-world compliance certificate.
- Every professional calculation must expose units and assumptions.
- Faults must be deterministic and reproducible.
- Components counted as functional must have tested behavior.
- Offline mode must open the simulator shell and cached educational data without a network.

## Responsive/accessibility matrix
Verify at 1920, 1440, 1366, 1024, 768, 430, 390 and 375 px; keyboard-only navigation; visible focus; non-colour status; reduced-motion preference.
