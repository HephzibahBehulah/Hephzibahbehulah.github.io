# Symbol Guide

VoltPRo keeps schematic symbols separate from physical panel assets.

Directories:

- `symbols/IEC/` — IEC-oriented schematic symbols.
- `symbols/ANSI/` — ANSI/IEEE-oriented schematic symbols.

The current Phase 2 core pack contains original SVG symbols for the first functional model set. It is not yet the complete 100+ IEC/ANSI library.

Symbols must be vector schematic geometry, not text labels inside boxes. Each file should have an accessible SVG title/aria label when rendered in the UI.

No WireONa assets are to be copied.
