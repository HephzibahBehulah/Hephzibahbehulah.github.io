# VoltPRo Release Gate

## Required before release
- npm test passes
- project schema and migrations validate
- DOL acceptance suite passes
- component model maturity is explicit
- third-party assets have attribution/licence records
- Apache-2.0 licence is consistent
- PWA cache includes required runtime modules
- safety disclaimer remains visible
- no WireONa proprietary code, assets or branding is bundled
- browser smoke test completed
- large-project performance profile reviewed

## Product statement

VoltPRo is an independent free/open-source electrical, electronics and automation learning simulator. It implements comparable educational workflows independently; it is not a copy of WireONa and does not certify real electrical installations.
